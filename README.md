- Only install on a device you can afford to lose

## Installation

1. Download the APK from [Releases](https://github.com/flexyyy007-tech/XM-DRIVER/releases/latest)
2. Enable **"Install unknown apps"** for your browser or file manager
3. Install the APK
4. Open the app
5. Grant root access when prompted
6. Load your driver
